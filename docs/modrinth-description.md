PokéEdit gives you an in-game editor for your Cobblemon party. Press **K** to open it, choose a slot, and see your Pokémon in 3D while you build its moveset and adjust its stats.

## Edit any party slot

- **Pokémon** lets you edit a nickname, change species, or add a Pokémon to an empty slot.
- **Stats** lets you change nature, IVs, EVs, and effective stats. Search for a nature by name or stat and see which stats it raises and lowers.
- **Moves** offers name search and Tab completion. Hover a move to see its type, power, accuracy, PP, and effect.

**Save** applies your changes. **Ctrl+1**, **Ctrl+2**, and **Ctrl+3** switch tabs. Use **Ctrl+S** to save from any tab.

## Use the staff or edit stats live

Get the PokéEdit Staff from the Creative **Tools** tab. Right-click to open your party. Admins can aim at another player in reach and right-click to open that player’s party. A rainbow outline shows who they are targeting.

Use `/stat live` for a dedicated stat editor with immediate updates. Direct stat changes work in battles through Cobblemon’s built-in Showdown simulator. The Pokémon keeps its stat bonuses as it levels up, evolves, or moves into PC storage.

## Install and play

Use **Minecraft Java Edition 1.21.1**, **Java 21**, **Fabric Loader 0.17.2 or later**, **Fabric API 0.116.6 or later** for Minecraft 1.21.1, and **Cobblemon 1.7.3 for Fabric**. Install PokéEdit in your instance, then press **K** or run `/stat ui` in game. On multiplayer servers, install the same release on the server and each client that opens the editor. Server owners can disable self-editing in `config/stateditor.json`.
